# SCNU综评审核标准

> **华南师范大学人工智能学院**全日制本科学生《综合素质测评登记表》审核 Skill。
> 以《华南师范大学人工智能学院全日制本科学生综合素质评价实施细则（2025）》为唯一计分依据，
> 审校登记表的分值、模块归属、材料真实性与时间合规性，产出可直接转发学生核对的问题汇总、
> 修订版登记表与原生 Word 批注版副本。

面向场景：学院奖学金 / 评优综测材料审核、年级与班委批量核查学生登记表、学院综合素质评议工作组复核。

- Skill 标识：`scnu-syntheses-evaluation-review`
- 显示名：**SCNU综评审核标准**
- 仓库：https://github.com/Gorilla-Kevv/scnu-syntheses-evaluation-review

## 一、用途

本 Skill 解决一个具体问题：**如何用统一、可复核的口径，批量审核一个学院学生的综测材料。**

人工审核的典型困境有三个：

1. **口径不统一** —— 同一条加分项，不同审核人算出不同分值。
2. **证据对不上** —— 登记表上写了 15 分，但佐证材料可能超期、缺姓名、或根本不属于该模块。
3. **反馈成本高** —— 审核意见散落在各处，学生看不懂自己哪里错、要补什么。

本 Skill 的应对方式：

- 把《实施细则》**逐条固化**为可复用的判定规则（见 `references/scoring_rules.md`）；
- 对**每一条加分项**要求"细则条款 + 佐证材料位置"双向可追溯；
- 产出**面向学生**的问题清单（四类问题 + 反馈勾选栏），以及**面向复核人**的批注版登记表（批注直接锚定在问题所在单元格上）。

核心原则：**不编造、不加码、不替学生"发明"加分项**。证据不成立或存疑的项，一律标注为"暂不计 / 待补证 / 须年级认定"，而非直接判负。

## 二、华南师范大学人工智能学院 特化说明

本 Skill 的标准与规则**针对华南师范大学人工智能学院（SCNU-AI）的综评场景特化**，体现在四个方面：

### 1. 评测维度：学院细则的五大模块权重

| 模块 | 权重 | 原始分构成 |
|---|---|---|
| 思想品德 | — | 民主测评分（满分 50）＋ 行为纪实加分 － 行为纪实扣分 |
| 学业表现 | **70%** | 学业成绩（教务系统绩点）＋ 学术研究 ＋ 学科竞赛 ＋ 创新发明 ＋ 专业技能 |
| 体育素养 | **5%** | 体质测试 ＋ 体育参与 ＋ 体育竞赛 － 扣分 |
| 美育素养 | **5%** | 美育参与 ＋ 美育竞赛 － 扣分 |
| 劳动素养 | **10%** | 劳动观念 ＋ 劳动实践 ＋ 群团活动 － 劳动实践扣分 |

评价节律（学院细则第三条）：每学期考核一次、每学年总评一次；第一、二、三学年总评在 **9 月**，第四学年在 **3 月**。

### 2. 评分规则：本 Skill 内置的判定规则

**时间合规（附则第二条，效力条款）**
> 所有加分、减分项的证明材料或证书落款日期均应在综合素质评价的时间范围内，不在期限内不予认可。

本 Skill 据此逐项校验落款日期，并特别核查：英语四六级考试年月、学代会/团代会证明、暑期三下乡、寒假社会实践、跨学年聘书。

**志愿服务时长转化（劳动·劳动实践）**

| 服务时长 | 24≤h<48 | 48≤h<96 | ≥96h |
|---|---|---|---|
| 加分 | 10 | 15 | 20 |

> 备注：**转化时长为上一学年内时长，不累计转化**。
> → 故"累计 xx 小时"的截图**不可直接转化**，必须索取本评优学年区间明细。

**折算与封顶规则（高频失分点）**

| 规则 | 内容 |
|---|---|
| 兼任职务 | 最高职务满分，**第二职务 50%**，其他不计 |
| 任职时长 | 满一学期以上未满一学年 → 按职务等级 **50%**；不足一学期 / 非客观原因离职 → **不加分** |
| 述职评议 | 优秀 **120%** / 合格 100% / 基本合格 80% / 不合格不计 |
| 团队获奖 | 第一负责人 100% / 第二至第五 70% / 其余 **50%** |
| 大创、课题 | **立项未结题按 60%** |
| 参与类封顶 | 体育参与、美育参与"每个项目类别累计不超过该项目的国家级加分" |
| 非榜单赛事 | 按推荐竞赛列表定级，榜外 → 按 **D 类 × 60%** |
| 团队竞赛排名 | 仅**前 5 名**计分（依据获奖表"竞赛参与人（按获奖证书顺序排列）"列） |
| 无等级项目 | 细则未说明等级的，**折中按二等奖**算分 |

**内容清理**
- 登记表模板自带的"格式示例"文字（如"全勤——3分／参加党校学习——1分"）**不是**加分项，应删除。
- "专业审核得分""年级审核得分"两栏**应由审核人填写**，学生自填的应清空。
- 学业成绩由**教务系统导出**，学生自填绩点不予认可。

完整数值（含思想品德行为纪实加减分、体育/美育各名次档次、劳动实践各项目、**九级岗位表**、表彰荣誉表）见
[`references/scoring_rules.md`](references/scoring_rules.md)。

### 3. 判定依据：每条结论都可追溯到细则条款

本 Skill 要求审核结论必须同时满足：

1. **能指出细则条款** —— 例如"参照第五条第（二）款第3点第（1）款"。
2. **能指出佐证材料位置** —— 例如"《院运会第六名.pdf》：2023-10-15，环境学院田径运动会男子100米第六名"。
3. **能指出判定理由** —— 例如"时间不在本评优学年内，且体育竞赛表院级第 6、7、8 名加分为 0"。

三者缺一，则该结论只能标注为"待核实"，不得出具分值判定。

### 4. 适用范围与注意事项

**适用范围**

- 适用主体：华南师范大学**人工智能学院**全日制本科学生。
- 适用材料：学院统一格式的《综合素质测评登记表》（附件 3），及其随附的获奖证书、聘书、成绩单、活动证明、名单页等佐证材料。
- 适用场景：学院/年级组织的奖学金评审、评优评先、学年总评的材料核查环节。

**注意事项（务必遵守）**

1. **本评优学年区间必须向用户确认** —— 不同年级/学院口径不同，不可默认自然年，也不可沿用他人模板中的区间。
2. **年级统一口径须先行确认** —— 例如"劳动实践周（劳动观念）10 分本学年统一不加分"属于年级口头通知、**不写入细则**。不得按细则字面加这 10 分。
3. **不越权认定** —— 以下事项超出审核人权限，必须交**年级辅导员 / 学院综合素质评议工作组**认定，在产出中明确标注：
   - 荣誉称号（优秀共青团员、优秀学生干部等）应归思想品德还是劳动·群团；
   - 转专业学生的身份归属与综测归属；
   - 艺术团训练、裁判等级、活动级别的认定。
4. **数值以当次细则原文为准** —— `references/scoring_rules.md` 中的数值取自学院 **2025 版**细则。若学院发布新版细则（如分值调整、新增白名单赛事），**以新版原文为准**。
5. **隐私与合规** —— 材料包含学号、成绩、家庭信息等个人敏感数据。本 Skill 全程**仅在本地处理**，不外发、不上传；仓库本身不包含任何学生数据。
6. **原件只读** —— 批注与修订只写在**副本**上，副本生成在原文件同级目录，原件绝不改动（完成后以 `mtime` 自证）。
7. **外院系套用需换标准** —— 若用于其他学院，须替换 `references/scoring_rules.md` 中的计分表与折算规则后方可使用。

## 三、这个 Skill 做什么

**输入**：一份《实施细则》+ 若干学生材料文件夹（docx / PDF / 图片 / xls）。

**输出**：

| 交付物 | 命名 | 说明 |
|---|---|---|
| 问题汇总 txt | `综合素质测评材料问题汇总（请各班委转发学生核对）.txt` | 按人分四类问题，附反馈勾选栏 |
| 修订版登记表 | `<姓名>（审核修订版）.docx` | 副本，写回修正后分值 |
| 批注版登记表 | `<姓名>（审核批注版）.docx` | 原生 Word 批注，锚定到具体单元格 |
| 逐人审核意见 | `<姓名>_材料审核意见.txt` | 单学生深度审核时使用 |
| 批注结果说明 | `审核批注结果说明.txt` | 逐份文档的批注条数、锚定位置、不可读材料清单 |

问题汇总的四类结构（便于学生逐条反馈）：

```
【NN】学号 姓名
  ◆ 一、材料有误之处：
  ◆ 二、加分项目描述模糊不清：
  ◆ 三、材料缺失情况：
  ◆ 四、存在疑问／需要核实的信息：
  ▶ 请本人反馈：
    □ 已更正    □ 已补充材料    □ 申请年级认定    □ 无此项（删除）
    补充说明：____________________________________________________
```

## 六、使用方式

### 6.1 通过对话触发（推荐）

Skill 会按 `description` 中的触发词自动加载，也可手动指定。典型触发语：

- 「根据实施细则，把这些学生的综测登记表审一下」
- 「把审核问题汇总成 txt，方便转发学生核对」
- 「在这些登记表的副本上批量批注」
- 「这是之前缺的某同学的材料，审一下」

审核流程为五步：

| 步骤 | 动作 |
|---|---|
| **Step 0 摸底** | 列目录树、解析细则计分表、**与用户确认本评优学年区间与年级统一口径**、建立学生清单 |
| **Step 1 定位登记表** | 遍历各文件夹的 `.docx`，**读取正文首段**判定是否为"附件3 综合素质测评登记表"（不得只看文件名） |
| **Step 2 审读材料** | 有文字层的 PDF 直接检索姓名；扫描件/图片逐页渲染视觉识别；xls/xlsx 读取定位本人行 |
| **Step 3 比对定分** | 逐条判定：计分 / 更正 / 暂不计 / 待年级认定 |
| **Step 4 生成交付物** | 问题汇总 txt + 修订版登记表 + 批注版登记表 |
| **Step 5 汇报** | 逐份说明批注条数、锚定位置、不可读材料清单、原件未改动的证据 |

### 6.2 脚本独立使用

两个脚本不依赖 Skill 机制，可直接调用：

```bash
# 1) 先 dump 目标登记表结构，拿到行号与字段名
python scripts/dump_docx.py 某学生登记表.docx --row 14

# 2) 写批注定义 JSON（见下），生成批注版副本
python scripts/annotate_docx.py notes.json --folder /path/to/学生文件夹
```

批注定义 `notes.json` 示例：

```json
{
  "src": "F:/path/学生登记表.docx",
  "author": "综测审核组",
  "initials": "SJ",
  "overview": {
    "anchor": ["hval", "姓名"],
    "fallback": ["lbl", 0, "姓名"],
    "text": "【审核总述】共发现 8 处问题……"
  },
  "notes": [
    { "anchor": ["val", 14, "劳动观念加分"], "text": "【问题1·分值应更正】……" },
    { "anchor": ["kw", "寒假社会实践专项调研比赛"], "text": "【问题2·时间超范围】……" }
  ]
}
```

锚点类型：

| 类型 | 形式 | 用途 |
|---|---|---|
| `hval` / `hlbl` | `["hval", "年级"]` | 表头字段的值 / 标签单元格 |
| `val` / `lbl` | `["val", 14, "劳动观念加分"]` | 第 N 行的值 / 标签单元格 |
| `kw` | `["kw", "关键词"]` | 含关键词的段落（忽略空白回退匹配） |

## 七、关键判定要点

1. **先定身份，再算分** —— 表头年级/学号/班级与材料所载不一致时（典型：材料显示 2023 级环境科学 20233331003，表头填 2024 级软件工程2班），须列"身份归属待认定"，**由年级认定后才能定分**。
2. **"累计时长" ≠ "本学年时长"** —— 同时核对登记表填写的数字与附件截图数字是否自洽。
3. **同一赛事不重复计分** —— 报名分 + 晋级分 + 获奖分指向同一阶段时只取一项。
4. **奖项等级不简单按名称或主办方判定** —— 以细则规定为准；无规定的交学院工作组评议定级。
5. **分院级/校级边界** —— 院级活动按院级档，注意院级田径第 6、7、8 名加分为 **0**。
6. **劳动实践周先问口径** —— 不要按细则字面直接加 10 分。
7. **姓名一致性** —— 佐证名单中的姓名用字与本人不一致（如"胡竣尧"vs"胡俊尧"）时，列为待核，请出具单位确认。

## 八、常见陷阱

1. **登记表文件名可能伪装成《实施细则》** —— SCNU-AI 的登记表常被存为《【2025】…实施细则(20250909)_1.docx`，正文才是"附件3 登记表"。**只看文件名会导致"误判缺登记表"**。
2. **模板"格式示例"被当加分项** —— 照抄会虚增分数。
3. **合并单元格** —— python-docx 的 `row.cells` 对合并单元格会重复返回同一 `tc`，须按 `id(cell._tc)` 去重后再按索引取 label/value。
4. **`kw` 锚点易失败** —— 关键词可能不独立成段。优先用 `("val", 行号, 字段)` 精确定位；表结构特殊的（如入团自荐表）再退回关键词锚定整段。
5. **扫描件不可读就跳过** —— 应逐页渲染 + 视觉识别，并在批注中说明"无文字层，本次已渲染识别，建议本人指认"。既不能假装读过，也不能拒读。
6. **在原件上改** —— 绝对禁止。只生成副本，事后用 mtime 自证原件未变。
7. **手工拼接汇总文件导致截断** —— 追加/修改单个学生段落后须重跑统计，保持人数与条数自洽。

## 九、约束与边界

- **仅副本、同级目录、不动原件** —— 副本生成在原文件**同级目录**，不得集中收拢到新文件夹。
- **不做无证据的推断** —— 分值判断须能指出细则条款 + 佐证材料位置。
- **不越权认定** —— 荣誉称号归属、转专业归属、艺术团/裁判等级等，交年级/学院认定并在产出中标注。
- **隐私与合规** —— 材料含学号、成绩等个人信息，仅在本地处理，不外发、不上传；本仓库不含任何学生数据。
- **数值以原文为准** —— `references/scoring_rules.md` 数值取自学院 2025 版细则；其他院系或新版细则需替换后方可使用。
- **学年区间与年级口径必须确认** —— 不可硬编码、不可沿用他人模板。

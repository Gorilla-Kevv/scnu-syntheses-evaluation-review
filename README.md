# campus-syntheses-evaluation-review

> 高校院系**综合素质测评（综测）材料审核** Skill —— 以《综合素质评价实施细则》为唯一计分依据，审校登记表的分值、模块归属、材料真实性与时间合规性，并产出可直接转发学生核对的问题汇总与批注版登记表。

面向场景：奖学金 / 评优综测材料审核、班委或年级干部批量核查学生登记表、学院评审小组复核。

## 这个 Skill 做什么

输入：一份《实施细则》+ 若干学生材料文件夹（docx / PDF / 图片 / xls）。
输出：

| 交付物 | 命名 | 说明 |
|---|---|---|
| 问题汇总 txt | `综合素质测评材料问题汇总（请各班委转发学生核对）.txt` | 按人分四类问题，附反馈勾选栏 |
| 修订版登记表 | `<姓名>（审核修订版）.docx` | 副本，写回修正后分值 |
| 批注版登记表 | `<姓名>（审核批注版）.docx` | 原生 Word 批注，锚定到具体单元格 |
| 逐人审核意见 | `<姓名>_材料审核意见.txt` | 单学生深度审核时使用 |

核心原则：**不编造、不加码、不替学生"发明"加分项**。拿不到证据的项一律列为"待补证 / 暂不计"，而非直接判负。

## 使用

Skill 会按 `description` 中的触发词自动加载，也可手动指定。典型触发语：

- 「根据实施细则，把这些学生的综测登记表审一下」
- 「把审核问题汇总成 txt，方便转发学生核对」
- 「在这些登记表的副本上批量批注」
- 「这是之前缺的某同学的材料，审一下」

### 脚本独立使用

两个脚本不依赖 Skill 机制，可直接调用：

```bash
# 1) 先 dump 目标登记表结构，拿到行号与字段名
python scripts/dump_docx.py 某学生登记表.docx --row 14

# 2) 写批注定义 JSON（见下），生成批注版副本
python scripts/annotate_docx.py notes.json --folder /path/to/学生文件夹
```

批注定义 `notes.json` 示例：

```json
{
  "src": "F:/path/学生登记表.docx",
  "author": "综测审核组",
  "initials": "SJ",
  "overview": {
    "anchor": ["hval", "姓名"],
    "fallback": ["lbl", 0, "姓名"],
    "text": "【审核总述】共发现 8 处问题……"
  },
  "notes": [
    { "anchor": ["val", 14, "劳动观念加分"], "text": "【问题1·分值应更正】……" },
    { "anchor": ["kw", "寒假社会实践专项调研比赛"], "text": "【问题2·时间超范围】……" }
  ]
}
```

锚点类型：

| 类型 | 形式 | 用途 |
|---|---|---|
| `hval` / `hlbl` | `["hval", "年级"]` | 表头字段的值 / 标签单元格 |
| `val` / `lbl` | `["val", 14, "劳动观念加分"]` | 第 N 行的值 / 标签单元格 |
| `kw` | `["kw", "关键词"]` | 含关键词的段落（忽略空白回退匹配） |

依赖：`python-docx >= 1.2.0`（1.1.x 不支持 `add_comment`）、`pymupdf`。

## 核心评审标准（摘要）

1. **时间合规**：证书/聘书/成绩单落款须落在本评优学年内；志愿服务遵循「转化时长为上一学年内时长，不累计转化」。
2. **分值正确**：注意档位、封顶（每类别不超过该项目国家级加分）、折算（兼任 50%、未结题 60%、述职优秀 120%）。
3. **模块归属**：主题团日→思想品德；宿舍长→劳动·群团；优秀共青团员归属须年级认定（不可自行择高）。
4. **材料支撑**：每条加分须有载明本人姓名的佐证；竞赛须有本校在职教师署名。
5. **无效内容清理**：模板自带的「格式示例」文字不是加分项；「专业/年级审核得分」两栏学生不得填写。

## 常见陷阱（完整清单见 SKILL.md）

1. **登记表文件名可能伪装成《实施细则》** —— 只看文件名会导致"误判缺登记表"。必须读正文首段确认。
2. **院级田径第 6、7、8 名加分为 0 分** —— 有奖状但无分，极易误判。
3. **"累计时长" ≠ "本学年时长"** —— 截图不可直接转化，且要核对登记表数字与附件数字是否自洽。
4. **合并单元格** —— python-docx 的 `row.cells` 会重复返回同一 `tc`，须按 `id(cell._tc)` 去重。
5. **`kw` 锚点易失败** —— 优先用 `("val", 行号, 字段)` 精确定位。
6. **扫描件不可读就跳过** —— 应逐页渲染 + 视觉识别，并在批注中说明原因。

## 约束与边界

- **仅副本、同级目录、不动原件**：批注/修订只写在副本上，副本生成在原文件同级目录。
- **不做无证据的推断**：分值判断须能指出细则条款 + 佐证材料位置。
- **不越权认定**：荣誉称号归属、转专业学生归属、艺术团/裁判等级认定等，交年级/学院认定。
- **隐私与合规**：材料含学号、成绩等个人信息，仅在本地处理，不外发、不上传。
- **数值以原文为准**：`references/scoring_rules.md` 中的数值取自华南师范大学人工智能学院 2025 版细则，其他院系请以当次提供的细则原文为准；学年区间与年级统一口径必须向用户确认，不可默认。
